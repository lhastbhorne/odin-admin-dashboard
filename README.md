
# Admin Dashboard

A responsive admin dashboard built with HTML and CSS as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

This project focuses on recreating an admin dashboard interface while practising modern CSS layout techniques, particularly CSS Grid and Flexbox.

## Features

- Dashboard sidebar with navigation links.
- Search bar and notification section.
- User profile and welcome section.
- Project cards displaying project information.
- Announcements section.
- Trending users section.
- Responsive layout for different screen sizes.

## Built With

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Media Queries

## What I Learned

Through this project, I practised:

- Structuring web pages with semantic HTML.
- Creating complex layouts using CSS Grid.
- Aligning and positioning elements with Flexbox.
- Working with CSS variables.
- Styling cards, buttons, and navigation elements.
- Making layouts responsive using media queries.
- Organising project files and assets.

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/lhastbhorne/odin-admin-dashboard.git
   ```

2. Navigate into the project directory:

   ```bash
   cd odin-admin-dashboard
   ```

3. Open `index.html` in your browser.

Alternatively, open the project folder in VS Code and use the Live Server extension.
